# 多智能体接入指南

R1R2 浏览器技能底层基于 **标准 MCP 协议** + **通用 SKILL.md 指令**，因此除了
ARCA.CSR.智驱，也可接入任意"能调 shell 或支持 MCP"的 AI 智能体。

> 说明：`arca-dsr-plugin.json` 是 ARCA.CSR 专属的插件包清单，其他智能体读不懂；
> 但 `SKILL.md`（Agent 指令）和 MCP Server（6 个 browser_* tools）是通用标准，
> 可被 Cursor / Qoder / Claude Code 等直接使用。

## 通用前置：安装 r1r2-bsk 与浏览器扩展

任意智能体接入前，先完成一次环境初始化（只需一次）：

```bash
# 1. 安装二进制 + 构建 MCP Server
bash scripts/install.sh

# 2. 安装浏览器扩展（Chrome/Edge，见 README）
#    Chrome: https://chromewebstore.google.com/detail/hhcmgoofomhgciiibhipgmgkgnoenaoi
#    Edge:   https://microsoftedge.microsoft.com/addons/detail/browserskill/emacgiaaaiojkkpkddmmdfhmokgmnikg

# 3. 启动 daemon
export BSK_HOME="$(pwd)/.bsk-home"
bin/r1r2-bsk daemon start
```

## 方式一：MCP Server 接入（推荐，Cursor / Qoder / Claude Code 均支持）

在对应智能体的 MCP 配置里，添加一个 stdio MCP server：

### Cursor

在 Cursor 的 `~/.cursor/mcp.json` 添加：

```json
{
  "mcpServers": {
    "r1r2-browserskill": {
      "command": "node",
      "args": ["/绝对路径/r1r2-browser-skill-plugin/mcp-server/dist/index.js"],
      "env": {
        "R1R2_BSK_PATH": "/绝对路径/r1r2-browser-skill-plugin/bin/r1r2-bsk",
        "R1R2_BSK_HOME": "/绝对路径/r1r2-browser-skill-plugin/.bsk-home"
      }
    }
  }
}
```

### Claude Code / Qoder

在 `~/.claude.json`（或 Qoder 的 MCP 配置）的 `mcpServers` 下添加同样结构。
配置后重启智能体，即可看到 6 个 `browser_*` 工具。

## 方式二：SKILL.md 接入（适用于任意 shell-capable 智能体）

把 SKILL.md 复制到对应智能体的 skills 目录：

| 智能体 | Skill 目录 |
|--------|-----------|
| Cursor | `~/.cursor/skills/r1r2-browser-skill/SKILL.md` |
| Claude Code | `~/.claude/skills/r1r2-browser-skill/SKILL.md` |
| Qoder | Qoder 配置的 skills 目录 |
| 其他 | 参照该智能体的 skill 加载约定 |

复制后，在对话里用自然语言描述任务即可。

## 6 个 browser_* 工具能力

| 工具 | 用途 |
|------|------|
| `browser_session` | 会话管理（start/stop/list） |
| `browser_page` | 页面导航（navigate/back/forward/reload/wait） |
| `browser_inspect` | 页面观察（observe/snapshot/html/screenshot/console/network） |
| `browser_interact` | 页面交互（click/hover/fill/select/press/focus/blur/wheel/scroll-to） |
| `browser_tabs` | 标签管理（list/create/select/close/borrow/return） |
| `browser_assist` | 辅助操作（resize/emulate/request-help） |
